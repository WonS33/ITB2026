# 06. 서비스팀 화면

출장보고서 데이터를 서비스팀 화면에서 집계한다. 기존에 생산팀 화면에 있던 출장보고서 집계는 이번 자료에 따라 서비스팀으로 옮겼다.

- 입력: 엑셀·PDF 업로드
- 열람: 당월·분기·연간
- 사용하는 원본 파일: 출장보고서 PDF (보고서 1건 = 출장 1회)

## 1. 지표와 표시 방식

| 지표 | 출장보고서 필드(샘플 값) | 표시 방식 (제안) | 주의할 점 |
|---|---|---|---|
| 출장 횟수 | 보고서 1건 = 1회. 출장 시작일·종료일(2026-09-29~09-30), 추가 출장(없음) | 숫자 카드 + 월별 추이 | (제안) 월 집계는 **출장 시작일** 기준. 여러 날 출장도 1회로 셈 |
| 출장 유상·무상 비율 | 비고 > 비용청구 유무(유상) | 원형 그래프 | 값이 유상·무상 두 가지뿐인지 확인 |
| 출장지 지역별 표시 | 요청처 구분(검색 불가), 요청처(예: ○○산업단지) | 한국 지도(제주 포함)에 점으로 표시. 너무 어려울 때만 지역별 순위 막대그래프 | 주소·지역 칸이 없음. 요청처 이름을 시·도로 바꾸는 대응표가 필요 |
| 교체 부품 순위 | 부품 사용 내역(Magnetic Contactor, Main Board, Control Room 등) | 가로 막대그래프 | PDF에서 긴 부품명이 "…"로 잘림. 작업 내용(메인보드 교체 등)과 표현이 다름 |
| A/S 제품 모델명 순위 | 제품 목록 > 모델명(AVA03), 수량(1대) | 가로 막대그래프 | 보고서 1건에 제품이 여러 개일 수 있음 |
| 교체 부품의 단가 | 보고서에 단가 칸이 없고 견적서 링크만 있음 | 부품별 단가 표와 기간별 변동 | 단가 출처(견적서, 부품 단가표 등) 확인 필요 |
| 출장 담당자 순위 | 작성자(예: ○○○ 대리), 동행자(예: ○○○ 대리) | 가로 막대그래프 | 작성자가 동행자에도 들어 있어 중복 집계 위험 → **보고서 1건당 1인 1회**로 셈 |

## 2. 함께 저장할 정보 (제안)

지표에 직접 쓰이지 않아도 상세 보기와 "요청 사유" 분석에 활용한다.

- 작업 구분(예: 수리), 사양, 일련번호, 고장 내용, 작업 내용, 작업 결과

## 3. 처리 규칙 (제안, 샘플에서 확인한 내용)

- **고장 내용**: 번호 목록 형태의 자유 서술이라 바로 순위를 매기기 어렵다. 처음에는 **저장·조회만** 한다. (필요하면 이후 "고장 유형" 선택 항목 추가를 검토)
- **일련번호 형식**: 출장보고서의 일련번호(A80018377702)는 제조내역 엑셀 규칙(타입 문자+국가+년도+4자리)과 형식이 다르다. 연결 가능 여부를 확인하기 전에는 **원문 그대로 저장만** 하고 제조내역과 연결하지 않는다.
- **PDF 추출**: 텍스트는 추출되지만 2~3단 배치라 **항목 이름 옆 위치로 값을 읽어야** 하고, 사진은 건너뛴다. 양식이 고정이면 자동 추출이 가능하다.
- **숫자 복원 (2026-10-18 샘플 확인)**: PDF 글꼴이 숫자 0~9를 특수 코드(U+E071~U+E07A)로 저장해서, 그대로 추출하면 날짜·모델명·일련번호의 숫자가 빠진다. U+E071=0 … U+E07A=9로 바꾸면 `2026-09-29`, `AVA03`, `A80018377702`가 정상으로 나온다. 자세한 내용은 [05](05-production.md) 4절 "샘플 파일 분석 결과".
- **업로드 후 확인·수정 화면을 반드시 둔다** ([03](03-common.md)). 잘린 부품명·요청처 이름은 이 단계에서 사람이 고친다.
- **지역 변환**: 요청처 이름 → 시·도 대응표를 두고, 대응표에 없는 요청처는 확인 화면에서 시·도를 직접 고르게 한다(제안). 지역은 시·도 이름으로 저장한다.
- 중복 확인 기준: (확인 필요) 보고서 고유 번호가 있는지. 없으면 **출장 시작일 + 요청처** 조합으로 확인한다(2026-10-18 팀 결정). 같은 날 같은 곳에 실제로 두 번 간 경우는 확인 화면에서 "중복 아님 — 저장"을 체크하면 저장할 수 있다.

## 4. 한국 지도 (핵심)

- 제주 포함 시·도 단위로 출장지를 점으로 표시한다.
- 도구 후보: 시·도 경계 GeoJSON + Leaflet 또는 SVG 지도 ([01](01-architecture.md)).
- 너무 어려울 때만 지역별 순위 막대그래프로 대체한다.

## 5. 어려울 때 대안

- 출장보고서 업로드가 어려우면 **표준 양식만 지원**, 또는 **웹 입력 폼**으로 대체한다.

## 6. 확인 필요

- 무상수리·유상수리 구분이 출장보고서에 적혀 있는지, 값이 두 가지뿐인지
- 요청처를 시·도로 바꿀 방법(거래처 목록에 주소가 있는지, 요청처 "검색 가능" 건은 주소가 연결되는지)
- 교체 부품 단가를 어디서 가져올지(견적서, 별도 부품 단가표 등)
- "단가 변동 사항"이 무엇과 무엇을 비교하는 것인지(제품별 단가 추이? 수리 비용?)
- 부품 사용 내역을 잘리지 않은 원본(엑셀 내보내기 등)으로 받을 수 있는지
- 출장보고서 일련번호(A800…)와 제조내역 일련번호(N…)의 관계
- 출장보고서 엑셀 양식이 있는지, 양식(열 이름·순서)이 고정인지

## 7. 권한

- 열람: 서비스팀 열람 권한자 + 대표·경영지원팀·관리자
- 업로드: 서비스팀 팀장(수정 권한자) + 대표·경영지원팀·관리자

## 8. 완료 기준

- [ ] 출장보고서 PDF를 업로드 → 확인·수정 → 저장할 수 있다
- [ ] 출장 횟수 카드와 월별 추이가 나온다
- [ ] 유상·무상 비율 원형 그래프가 나온다
- [ ] 교체 부품·A/S 모델명·담당자 순위 가로 막대그래프가 나온다 (담당자 중복 집계 없음)
- [ ] 한국 지도(또는 대안 막대그래프)에 출장지가 표시된다
- [ ] 당월·분기·연간 전환이 된다
- [ ] 서비스팀 팀원은 업로드가 막힌다
