# 11. 기업에 확인할 질문 목록

미팅에서 모호하거나 언급되지 않은 부분이다. 1주차 안에 답을 받는 것을 목표로 한다.
답을 받으면 체크하고, 답변 내용과 날짜를 적은 뒤 관련 spec 파일에 반영한다.

## 자료 요청

- [ ] 현재 사용 중인 수금·실적 엑셀 파일과 생산 엑셀 파일 샘플(민감 정보는 가린 버전) → [03](03-common.md)
- [ ] 출장보고서(엑셀·PDF) 샘플 2~3건과 제조내역 엑셀 샘플, 그리고 양식(열 이름·순서)이 고정되어 있는지 → [05](05-production.md), [06](06-service.md)
- [ ] 그래프 디자인 레퍼런스와 다우오피스 화면 캡처 → [03](03-common.md)

- [ ] 판매처 카테고리 전체 목록(상하수도, 발전소 외)과 제품 시리즈 전체 목록 → [05](05-production.md)
- [ ] 매출 기준이 계약·출고·수금 중 어느 시점인지 → [04](04-main-management.md)
- [ ] 분기 기준이 1~3월부터 시작하는 일반 달력 기준인지 → [09](09-metrics.md)
- [ ] "단가 변동 사항"이 무엇과 무엇을 비교하는 것인지(제품별 단가 추이? 수리 비용?) → [06](06-service.md) (임시: 부품별 직전 단가 대비 증감 + 이력, 2026-10-21)
- [ ] 무상수리·유상수리 구분이 출장보고서에 적혀 있는지 → [06](06-service.md)

## 권한·운영

- [ ] "생산팀/서비스팀(겸직)": 사실상 같은 직원이 두 팀 일을 함께 맡는 것으로 파악됨. 팀장도 한 명인지, 두 팀의 수정 권한을 같은 사람이 갖는지 최종 확인 → [02](02-users-permissions.md)
- [ ] 산업 분야·제품 비중을 메인 화면에 보여줄 때 판매량(수량)과 매출액 중 어느 기준으로 할지 → [04](04-main-management.md)
- [ ] 팀원이 실적을 직접 입력할 일은 없는지(입력은 팀장만 하는지) → [02](02-users-permissions.md)
- [ ] AI 코멘트를 위해 매출 데이터를 외부 AI 서비스에 보내도 되는지 → [04](04-main-management.md)
- [ ] 프로젝트 종료 후 실제 사용 계획이 있는지(배포·서버 운영 범위 결정에 필요)

## 지침 본문의 "확인 필요" 중 위 목록에 없던 항목 (팀 추가)

- [ ] 미수금 현황 형식: 거래처별 금액인지, 기간별 합계인지 → [04](04-main-management.md)

- [ ] 출장보고서의 유상·무상 값이 두 가지뿐인지 → [06](06-service.md)
