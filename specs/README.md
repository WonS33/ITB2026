# specs — 상세 요구사항 문서

근거 문서: 「경영지표 대시보드 프로젝트 지침 (기업 미팅 반영판)」 (2026-10-17)

## 표시 규칙

| 표시 | 뜻 |
|---|---|
| (표시 없음) / **확정** | 기업 미팅에서 직접 요청한 내용 |
| **(제안)** | 팀이나 AI가 구현을 위해 덧붙인 방법·기준. 기업 확인 전까지 바뀔 수 있음 |
| **(확인 필요)** | 미팅에서 언급되지 않았거나 모호한 내용. [11-open-questions.md](11-open-questions.md)로 기업에 확인 |

## 기존 지침과 미팅 내용의 관계

- 기존 지침(초기 요구사항)을 기본 토대로 삼고, 기업 미팅 요구사항을 더해 구체화한다.
- 둘이 **충돌할 때만** 미팅 내용을 우선한다.
- 기존 지침의 기능(원가·이익률, 자금수지 예측, BEP 등)은 구현 대상에 포함하되, **기업이 확정한 기능을 먼저 완성한 뒤** 진행한다.

### 기존 지침에서 조정된 내용

| 기존 지침 | 조정 결과 | 이유 |
|---|---|---|
| 직원이 소속 팀 실적 입력 | 팀장(및 경영지원팀·대표·관리자)만 입력·수정, 팀원은 열람만 | 미팅에서 "팀장만 수정 권한"으로 확정 |
| 관리자 기능 / 직원 기능 2단계 | 경영지원팀 메인, 생산팀, 서비스팀 화면 + 관리자 페이지 | 미팅에서 팀별 화면으로 요청 |
| 파일 업로드 | 엑셀(과거 데이터·생산 실적), 생산팀·서비스팀의 엑셀·PDF 업로드로 구체화 | 미팅에서 용도 확정 |
| 계정 인증 | 일괄 발급 + 본인 비번 변경 + 관리자 초기화 | 미팅에서 방식 확정 |
| 누적 지표·월별 리포트 | 당월·분기·연간 보기로 대체 | 미팅에서 기간 기준 확정 |
| 원가·이익률, 자금수지 예측, BEP, 공장 가동률, 수주 잔고·영업 파이프라인, 인당 생산성 | 구현(기업 확정 기능 이후) | 지표 정의·계산 데이터는 기업 확인 필요 |

미팅에서 새로 추가된 항목: AI 분석 코멘트, 출장보고서 자동 집계, 한국 지도 시각화, 관리자의 권한 등록·해제, 과거 데이터 이관.

## 근거 우선순위

1. 기업 관계자 미팅 내용과 이후 기업의 공식 피드백 (가장 최근 것 우선)
2. 교수자·멘토의 공식 지침
3. 팀이 합의한 최신 설계 문서 (이 specs 폴더)
4. 기존 프로젝트 파일과 이전 대화에서 확정된 결정 (초기 지침 포함)
5. 일반적인 개발 지식과 AI의 제안

중요한 내용이 충돌하면 임의로 고르지 않고, 차이점을 정리해 기업이나 멘토에게 확인한다.

## 문서 갱신 규칙

- 기업 답변을 받으면 해당 spec에 반영하고 [11-open-questions.md](11-open-questions.md)에서 체크한다.
- 결정 내용과 바꾼 이유는 각 파일 맨 아래 "변경 기록"에 날짜와 함께 적는다.
