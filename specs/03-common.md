# 03. 공통 기능

기능은 공통 기능과 팀별 화면 세 개(경영지원팀 메인, 생산팀, 서비스팀)로 나뉜다. 여기에 관리자 페이지와 본인 비밀번호 변경이 더해진다.

## 1. 화면 목록 (제안)

| 화면 | 사용 가능한 사람 | 상세 |
|---|---|---|
| 로그인 | 모두 | [02](02-users-permissions.md) |
| 비밀번호 변경 | 로그인한 모두 | [02](02-users-permissions.md) |
| 경영지원팀 메인 | 대표·경영지원팀·관리자 | [04](04-main-management.md) |
| 생산팀 | 생산팀 열람 권한자 | [05](05-production.md) |
| 서비스팀 | 서비스팀 열람 권한자 | [06](06-service.md) |
| 관리자 페이지 | 대표·경영지원팀·관리자 | [02](02-users-permissions.md) |

- 상단(또는 왼쪽) 메뉴에는 열람 권한이 있는 화면만 보인다.

## 2. 입력 방식 (확정)

| 팀 | 입력 방법 |
|---|---|
| 경영지원팀 | 숫자를 웹에서 직접 입력 |
| 생산팀·서비스팀 | 엑셀·PDF 파일을 업로드해 데이터 반영 (목표 생산량은 웹 입력) |

## 3. 기간 보기 (확정)

- 모든 팀 화면은 **당월·분기·연간** 세 가지 기준으로 볼 수 있다.
- (제안) 데이터는 **월 단위로 저장**하고, 분기·연간은 합산해 자동 계산한다.
- (제안) 화면 위쪽에 기간 선택 영역을 둔다: 연도 선택 + [당월 / 분기 / 연간] 전환 + (분기일 때) 1~4분기 선택.
- (확인 필요) 분기 기준이 1~3월부터 시작하는 일반 달력 기준인지. 확인 전에는 일반 달력 기준(1분기 = 1~3월)으로 개발한다.
- 어려울 때 대안: 분기 보기만 먼저 구현.

## 4. 파일 업로드 공통 흐름 (제안)

모든 업로드는 **추출 결과를 확인·수정한 뒤 저장**하는 단계를 둔다.

```
① 파일 선택·업로드
② 서버가 데이터를 추출 (아직 DB에 저장하지 않음)
③ 화면에 추출 결과를 표로 보여줌
   - 누락(필수값 없음), 중복(이미 저장된 기준 번호), 형식 오류(날짜·숫자) 표시
④ 사람이 확인하고 필요한 칸을 수정
⑤ [저장] → DB 반영
```

- 엑셀을 먼저 지원하고, PDF는 정해진 양식만 지원한다. PDF는 표 추출이 불안정할 수 있기 때문이다.
- 같은 파일을 두 번 올려도 중복 저장되지 않도록 기준 번호(일련번호, 판매번호 등)로 확인한다.
- 업로드 종류별 세부 규칙은 [05-production.md](05-production.md), [06-service.md](06-service.md)를 본다.

## 5. 과거 데이터 이관 (확정, 우선순위: 선택)

- 기존 엑셀 파일을 업로드하면 과거 데이터가 반영된다.
- 일정상 어려우면 "나중에 직접 입력"으로 대체할 수 있다.
- 어려울 때 대안: 정해진 양식 엑셀만 지원, 또는 직접 입력.
- (확인 필요) 현재 사용 중인 수금·실적 엑셀 파일의 양식.

## 6. UI 방향 (확정)

- 현재 사용 중인 **다우오피스 화면**을 참고한다.
- 그래프 디자인 레퍼런스는 기업에서 보내줄 예정이다. 받기 전까지는 **레이아웃과 기능 위주로** 개발한다.
- 기본 레이아웃과 버튼 스타일은 Bootstrap 5.0을 쓴다.
