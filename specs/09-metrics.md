# 09. 지표 정의

지표마다 정의, 계산식, 단위, 집계 기간을 여기에 남긴다. **여기 없는 계산식은 임의로 만들지 않는다.**

## 1. 기간 규칙 (제안)

| 보기 | 범위 |
|---|---|
| 당월 | 선택한 연·월 |
| 분기 | 1분기 1~3월, 2분기 4~6월, 3분기 7~9월, 4분기 10~12월 (일반 달력 기준, 확인 필요) |
| 연간 | 1~12월 |

- 데이터는 월 단위로 저장하고, 분기·연간은 월 값을 합산한다.

## 2. 경영지원팀 지표

| 지표 | 계산식 | 단위 | 상태 |
|---|---|---|---|
| 총매출 | 제품 매출 + 상품 매출 + 용역 매출 | 원 | 제안, 기업 확인 필요 |
| 총매입 | 상품 매입 + 원재료 매입 | 원 | 제안, 기업 확인 필요 |
| 총지출 | 경비 지출 + 그 외 지출 | 원 | 제안, 기업 확인 필요 |
| 간이 이익 | 총매출 − 총매입 − 총지출 | 원 | 제안, 기업 확인 필요. 화면에 "간이 지표" 표시 |
| 간이 이익률 | 간이 이익 ÷ 총매출 × 100 | % | 제안, 기업 확인 필요. 총매출이 0이면 표시하지 않음 |
| 연간 목표매출 달성률 | 기간 누적 총매출 ÷ 연간 목표매출 × 100 | % | 제안, 기업 확인 필요 |
| 매출 구성 비중 | 제품·상품·용역 매출 각각 ÷ 총매출 × 100 | % | 확정(표시), 계산식 제안 |

- 간이 지표는 회계상 원가·이익과 다를 수 있다.
- 이 값들이 추가 구현 지표(원가·이익률, BEP 등)의 기초가 된다.

## 3. 생산팀 지표

| 지표 | 계산식 | 단위 | 상태 |
|---|---|---|---|
| 기간 생산량 | 제조내역의 제조년월이 기간에 속하는 행(일련번호) 수 | 대 | 제안 |
| 생산량 달성률 | 기간 생산량 ÷ 기간 목표 생산량 × 100 | % | 제안, 기업 확인 필요 |
| 부족치 | 기간 목표 생산량 − 기간 생산량 (0보다 작으면 0) | 대 | 제안, 기업 확인 필요 |
| 산업 분야별 판매량 | 수주서 사업구분을 7개 분야로 묶어 제품 수량 합계 | 대 | 제안 |
| 거래처별 판매량 | 판매처별 제품 수량 합계 | 대 | 제안 |
| 제품별 판매량 | 품명별 수량 합계 | 대 | 제안 |

- (확인 필요) 당월·분기의 "기간 목표 생산량"을 어떻게 정할지. 지침에는 연간 목표만 있다. 확인 전 임시 기준: 연간 목표 ÷ 12 × 기간 개월 수 (제안).
- (확인 필요) 판매량 집계 기간의 기준 날짜(납기일, 납품일 등). 확인 전에는 수주서 납기일 기준으로 둔다(제안).

## 4. 서비스팀 지표

| 지표 | 계산식 | 단위 | 상태 |
|---|---|---|---|
| 출장 횟수 | 출장 시작일이 기간에 속하는 보고서 수 (여러 날 출장도 1회) | 회 | 제안 |
| 유상·무상 비율 | 비용청구 유무별 보고서 수 ÷ 전체 보고서 수 × 100 | % | 제안 |
| 지역별 출장 | 시·도별 보고서 수 | 회 | 제안 |
| 교체 부품 순위 | 부품명별 사용 횟수(또는 수량) 합계 내림차순 | 회/개 | 제안 |
| A/S 제품 모델명 순위 | 모델명별 수량 합계 내림차순 | 대 | 제안 |
| 출장 담당자 순위 | 작성자+동행자를 합쳐 보고서 1건당 1인 1회로 센 횟수 | 회 | 제안 |
| 부품별 단가·기간별 변동 | 단가 출처 확인 후 정의 | 원 | 확인 필요 |

## 5. 추가 구현 지표 (기업 확정 기능 이후)

아래 지표는 구현 대상이지만, **정의와 계산 데이터를 기업에 확인한 뒤** 이 표에 계산식을 채운다. 실제 데이터가 없는 지표는 가상 데이터로 화면을 구현하고, 끝내 못 한 지표는 발표에서 향후 계획으로 소개한다.

| 지표 | 계산식 | 필요한 데이터 | 상태 |
|---|---|---|---|
| 원가·이익률 | 미정 | 원가 | 확인 필요 |
| 매입·매출·미수 | 미정 | 매입, 매출, 미수 | 확인 필요 |
| 자금수지 예측 (3~6개월) | 미정 | 미정 | 확인 필요. 예측값은 실제값과 구분 표시, 계산 방법과 한계를 함께 적음 |
| BEP 달성 현황 | 미정 | 고정비·변동비 구분 | 확인 필요 |
| 생산량·공장 가동률 | 미정 | 공장 가동 시간 | 확인 필요 |
| 수주 잔고·영업 파이프라인 | 미정 | 수주 잔고 | 확인 필요 |
| 인당 생산성 | 미정 | 미정 | 확인 필요 |
