# 05. 생산팀 화면

입력은 엑셀·PDF 업로드(목표 생산량은 웹 입력), 열람은 당월·분기·연간 기준이다.

사용하는 원본 파일:

- **샘플 1: 제조내역 엑셀** — 제품 1대(일련번호)당 1행
- **샘플 2: 수주서 PDF** — 주문 1건당 1장

## 1. 생산·판매 실적

| 항목 | 내용 | 데이터 출처 (제안) |
|---|---|---|
| 연간 목표 생산량 | 웹에서 입력 | 웹 입력 |
| 월간 생산량 | 목표 대비 달성률(%)과 부족치를 당월·분기·연간으로 표시 | 제조내역 엑셀의 **제조년월** 기준으로 대수를 셈 |
| 산업 분야별 판매량 | 상하수도, 발전소, 가스, 오일, 석유, 민간 플랜트, 기타 (7개) | 수주서 PDF의 "사업구분" 값(예: 상하수도(지자체))을 7개 분야로 묶어 집계 |
| 거래처별 판매량 | 실제 판매처 기준 | 수주서의 판매처 또는 제조내역 엑셀의 거래처 열 |
| 제품별 판매량 | 품명별 수량 | 수주서 제품정보의 품명과 수량(예: 제수 150A: NTI-03, 3대) |

- (제안) 판매량은 **순위 막대그래프**와 **비중 원형 그래프**로 보여준다.
- 산업 분야·제품 데이터는 경영지원팀 메인 화면의 "산업 분야·제품 비중"에도 쓰인다([04](04-main-management.md)).
- (확인 필요) 연간 목표 생산량은 누가, 언제 입력하는지.
- (확인 필요) 수주서 "사업구분" 값 전체 목록과 7개 산업 분야 대응 기준. 확인 전에는 대응표를 설정값으로 두고 모르는 값은 "기타"로 분류한다(제안).
- (확인 필요) 판매처 카테고리 전체 목록과 제품 시리즈 전체 목록.
- 달성률·부족치 계산식은 [09-metrics.md](09-metrics.md)를 따른다.

## 2. 일련번호 조회

제조내역 엑셀을 업로드해 두면, 일련번호로 검색했을 때 아래 11개 정보를 보여준다. 엑셀에 없는 항목은 수주서 PDF로 보완한다.

| 번호 | 조회 항목 | 제조내역 엑셀 열 | 수주서 PDF 필드 | 주의할 점 |
|---|---|---|---|---|
| 1 | 제품 사양 | 모델명(뒤 2자리만, 예: 04), 부시 가공(6자리 숫자), rpm, 전원 | 품명(예: 제수 150A: NTI-03), 전원, Flange, RPM/OT, 스템/부시가공 | 플랜지는 엑셀에 열이 없어 PDF에서만 얻을 수 있음. 엑셀은 rpm·전원이 일부 행에만 적혀 있음 |
| 2 | 제조년월 | 제조년월 | 없음 | 실제로는 일 단위 날짜로 저장됨(예: 2026-01-09) |
| 3 | 검사일자 | 검사일자 | 없음 | |
| 4 | 검사번호 | 검사번호(뒤 3자리만, 예: 001) | 없음 | 전체 번호 = NTK + 년도 2자리 + 3자리 |
| 5 | 수주번호 | 뉴토크 번호의 PO번호(예: 26006), SO번호(샘플에서는 빈칸) | 판매번호(예: NTK-SO-260000), 수주번호(빈칸), 수주서류(#26024…) | 두 파일을 잇는 기준 번호 확인 필요 |
| 6 | 판매처 | 거래처 | 판매처 | PDF는 긴 이름이 "…"로 잘려 출력됨 |
| 7 | 최종발주처 | 최종발주처 | 최종발주처/EPC | |
| 8 | 사업명 | 사업명 | 사업명 | |
| 9 | 출고일자 | 출고일 | 납품일/출장일 | |
| 10 | 납기일자 | 납기일 | 납기일 | 3절 캘린더에도 사용 |
| 11 | 비고 | 비고(기타, 방폭 여부 등) | 제작관련 공통사양/비고 | |

### 검색 방식 (제안)

- 엑셀에는 일련번호 4자리(예: 0001)만 적혀 있다.
- 작성 규칙상 전체 일련번호 = **타입 문자(N/M/B/Q/C/P/NE) + 국가번호 2자리 + 년도 2자리 + 4자리**.
- 저장할 때 전체 번호를 만들어 두고, **4자리·전체 번호 어느 쪽으로 검색해도** 찾게 한다.
- 4자리로 검색해 여러 건이 나오면 목록으로 보여주고 하나를 고르게 한다.

## 3. 당월 납기 캘린더

- 당월 납기일을 캘린더에 **수주번호별로** 표시한다.
- (제안) 납기일자는 제조내역 엑셀에서 가져오므로, 일련번호 조회와 캘린더는 같은 데이터를 함께 쓴다.
- (제안) 날짜를 누르면 그날 납기인 수주번호와 판매처·사업명을 보여준다.
- 실무에서 **납기일 도래 확인용**으로 쓴다(기업 확인, 2026-10-27).
- **처리 상태 구분**(제안): 제조내역의 **출고일**로 판단한다. 수주 묶음(납기일+수주번호)의 모든 대수에 출고일이 있으면 출고 완료, 일부만 있으면 일부 출고, 없으면 출고 전, 출고가 끝나지 않았는데 납기일이 지났으면 납기 지남. 캘린더에서 앞으로 처리할 건은 진한 색, 출고 완료 건은 회색으로 흐리게 표시하고 기호(! ○ ◐ ✓)와 글자를 함께 붙인다. 범례에 상태별 건수, "출고 완료 건 숨기기" 스위치
- **납기 임박**(대시보드 맨 위): 출고가 끝나지 않은 수주 중 오늘부터 14일 안 + 납기 지남(최근 30일). D-day(D-3, D-day, D+2), 납기일, 수주번호, 판매처, 사업명, 출고/대수, 상태. 기간 선택과 관계없이 오늘 기준. 날짜를 누르면 캘린더의 그 날짜로 이동
- **검색**(2026-10-27): 캘린더 **아래** "납기 검색" 카드(일련번호 조회 카드와 같은 모양)에서 수주번호(# 없이도)·판매처·사업명·일련번호·거래처 주문번호로 **모든 달**을 찾는다. 결과는 최근 납기일부터 최대 50건, 상태·납기일(D-day)·수주번호·판매처·사업명·출고/대수. 줄을 누르면 위 달력으로 올라가 그 달·날짜 상세를 열고, 이번 달 칸에서 검색에 걸린 수주는 테두리로 강조. 일련번호로 찾아도 그 수주 묶음 전체를 보여준다
- (확인 필요) 실무에서 "처리 완료"를 출고로 보는지, 다른 기준(설치 완료 등)이 있는지. 임박 기준 14일이 맞는지

## 4. 업로드 처리 규칙 (제안, 샘플 파일에서 확인한 내용)

### 제조내역 엑셀

- 연도별 시트(예: `2026(NTI)`)로 되어 있다.
- 위쪽에 작성방법 안내가 있고 제목이 두 줄(병합)이다. **안내·제목 행은 건너뛰고 데이터 행만 읽는다.**
- 엑셀 날짜가 숫자(예: 46031)로 읽히면 날짜(2026-01-09)로 바꿔 저장한다.
- 일련번호 없이 오른쪽 끝 OPUN·CLUN·OPLO·CLLO 열에만 숫자가 있는 행이 많다. **일련번호가 없는 행은 제외한다.**
- 중복 확인 기준: 전체 일련번호.
- 업로드 후 확인·수정 화면을 거쳐 저장한다([03](03-common.md)).

### 수주서 PDF

- 주문 1건당 1장이고 텍스트 추출은 된다.
- 긴 값이 "…"로 잘린 채 출력되므로, 확인 화면에서 사람이 고칠 수 있게 한다.
- 가능하면 PDF보다 엑셀이나 시스템 내보내기 원본을 받는다.
- 중복 확인 기준: 판매번호(예: NTK-SO-260000) (확인 필요).

### 샘플 파일 분석 결과 (2026-10-18)

**제조내역 엑셀 (`샘플_1.xlsx`, 시트 `2026(NTI)`)**

- 1~5행은 작성방법 안내, 7행은 연도 제목, 8~9행은 두 줄 제목(병합)이다. 데이터는 **10행부터** 시작한다.
- 셀에는 짧은 값만 저장하고, 나머지는 **셀 표시 형식**으로 붙여서 보여준다. CSV로 저장하면 붙인 결과가 나온다.

| 열 | 항목 | 셀 값 | 표시 형식 | 화면에 보이는 값 |
|---|---|---|---|---|
| B | 일련번호 | `0001` | `"N8226"@` | N82260001 |
| C | 모델명 | `04` | `"NTI-"@` | NTI-04 |
| D | 부시 가공 | `301008` | `"Ø"##"x"##"x"##` | Ø30x10x08 |
| I | 검사번호 | `001` | `"NTK26"@` | NTK26001 |
| J | 뉴토크 PO번호 | `26006` | `"#"@` | #26006 |

- → **전체 일련번호의 타입 문자·국가번호·년도는 셀 표시 형식에서 자동으로 읽는다.** 샘플은 `N`(기본) + `82`(한국) + `26`(년도). 표시 형식이 없는 셀은 확인 화면에서 사람이 입력한다.
- 날짜(G 제조년월, H 검사일자, P 납기일, Q 출고일)는 엑셀 날짜 형식이라 openpyxl이 날짜로 바로 읽는다. 숫자(예: 46031)로 읽히는 경우를 대비한 변환도 둔다.
- 열 순서: B 일련번호, C 모델명, D 부시 가공, E rpm, F 전원, G 제조년월, H 검사일자, I 검사번호, J PO번호, K SO번호, **L 거래처 주문번호**(명세에 없던 열), M 거래처, N 최종발주처, O 사업명, **P 납기일, Q 출고일**, R 비고, S 기타, U 비고(2), V~Y OPUN·CLUN·OPLO·CLLO.
- 일련번호가 있는 행은 샘플에서 6행뿐이다. 나머지 수백 행은 OPUN 등 숫자만 있거나 S열에 `P028ZZ249-…`, `MOV-S201A` 같은 값, U·V열에 "완제품"·"신형 메인보드"가 있다. **일련번호가 없는 행은 제외한다**(기존 규칙 유지).

**수주서 PDF (`샘플_2.pdf`)와 출장보고서 PDF**

- ⚠️ PDF 글꼴(Pretendard)이 **숫자 0~9를 특수 코드(U+E071~U+E07A)로 저장**한다. 그대로 추출하면 숫자가 모두 빠진다(예: `NTK-SO-260000` → `NTK-SO-`). U+E071=0 … U+E07A=9로 바꾸면 정상 복원되는 것을 확인했다. 나머지 코드도 확인했다(Phase 7): U+E093=`,` U+E094=`.` U+E095=`:`.
- 수주서에 명세에 없던 항목이 있다: 브랜드 구분(NEWTORK), 작업 구분(제품), 수출 구분(내수), **수주일**(2026-01-27), 출고된 리모컨 수, 매출액, 결제방법.
- 수주서류 값 `#26024 (파일 이름)…`의 `#26024`는 제조내역 PO번호(`#26006` 형식)와 모양이 같다. **두 파일을 잇는 기준 번호일 가능성이 높지만 기업 확인이 필요하다.**

### 확인 필요

- 제조내역 엑셀의 열 이름·순서가 매번 같은지
- 수주번호 하나에 일련번호 여러 개가 묶이는지
- 제조내역 엑셀과 수주서를 잇는 기준 번호(뉴토크 PO번호, 판매번호 NTK-SO-…, 수주서류 #번호 중 무엇인지)
- 일련번호의 타입 문자와 국가번호를 어디서 가져오는지(시트 이름의 NTI? 모델별 규칙?)
- 엑셀의 rpm·전원 빈칸이 "위 행과 같음"인지, 값이 없는 것인지
- OPUN·CLUN·OPLO·CLLO 열의 의미와 조회 화면에 보여줄지

## 5. 권한

- 열람: 생산팀 열람 권한자 + 대표·경영지원팀·관리자
- 업로드·목표 생산량 입력: 생산팀 팀장(수정 권한자) + 대표·경영지원팀·관리자

## 6. 완료 기준

- [x] 연간 목표 생산량을 입력하면 당월·분기·연간 달성률과 부족치가 나온다 (2026-10-18 확인: 목표 입력 카드 + 숫자 카드, 테스트 ProductionSummaryTests)
- [x] 제조내역 엑셀을 업로드 → 확인·수정 → 저장할 수 있다 (2026-10-18 확인: 실제 샘플 6행 추출, 가상 파일로 화면 경유 흐름 확인)
- [x] 같은 엑셀을 다시 올려도 중복 저장되지 않는다 (2026-10-18 확인: 같은 파일 재업로드 시 전부 "이미 저장됨")
- [x] 산업 분야·거래처·제품별 판매량이 순위 막대·비중 원형 그래프로 나온다 (2026-10-18 확인: 산업 분야는 원형+막대, 거래처·제품은 순위 막대에 비중 % 표시로 조정 — 변경 기록 참고)

- [x] 당월 납기 캘린더에 수주번호가 표시되고, 날짜를 누르면 상세가 나온다 (2026-10-18 확인: 화면 캡처로 확인)

## 7. 제조내역·수주 내역 목록 (2026-10-27, 사용자 요청 + 제안)

- **제조내역 목록**(`/production/records`, 조회 메뉴): 기간 안의 제조내역을 표로 훑어본다. 기간 기준은 **제조년월**(대시보드 생산량과 같음). 열: 일련번호, 모델, 제조년월, 검사일자, 거래처, 사업명, PO번호, 납기일, 출고(✓ 출고일 / ○ 출고 전). 걸러내기: 검색어(일련번호·거래처·최종발주처·사업명·PO번호·거래처 주문번호), 모델명, 출고 상태(건수 표시). 100건씩, 최근 제조 순. 줄을 누르면 일련번호 조회 화면에서 11개 항목 상세를 연다. 수정·삭제는 없음(업로드로만 바꿈)
- **수주 내역 목록**(`/production/orders`, 제안): 올린 수주서를 **납기일** 기준으로 본다(대시보드 판매량과 같음). 열: 납기일, 판매번호, 수주서류, 수주일, 산업 분야, 판매처, 사업명, 제품×수량, 수량 합계. 걸러내기: 검색어(판매번호·수주서류 번호·판매처·최종발주처·사업명·품명), 산업 분야. 줄을 누르면 제품 정보 전체(전원·Flange·RPM/OT·스템/부시가공)와 최종발주처·사업구분 원문·납품일·비고를 펼친다
- **엑셀 내려받기**(제안): 두 목록 모두 지금 걸러 놓은 조건 그대로 전체(쪽 나눔 없이)를 .xlsx로. 제조내역은 업로드 엑셀의 모든 열, 수주 내역은 제품 1개 = 1행(주문 정보 반복). 날짜는 YYYY-MM-DD 글자
- **대시보드에서 이동**(제안): 월별 생산량 막대를 누르면 그 달(당월 보기)로 바꿔 제조내역 목록으로, 모델별 생산 도넛·표에서 모델을 누르면 그 모델로 걸러진 제조내역 목록으로 간다

## 8. 업로드 이력 (2026-10-27, 제안 — 서비스팀도 같음)

- `/production/uploads`(데이터 입력 메뉴, 수정 권한자만): 그 팀 파일 종류(제조내역 엑셀·수주서 PDF)의 업로드 기록 최근 100건. 올린 시각, 올린 사람, 종류, 파일 이름, 상태(✓ 저장 완료 / … 확인 대기 / ✕ 취소), 추출 행 수, 저장 건수. 원본 파일은 보관하지 않으므로 내려받기는 없음
